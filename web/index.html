Getting Started in Seconds

How to install and run Tidy Mac on your local machine.

1

Download the DMG or ZIP

Click the download button above to get TidyMac.dmg or TidyMac.zip, or run the terminal install command.

2

Drag to Applications

Open the disk image and drag TidyMac.app into your Applications folder.

3

Launch & Grant Permissions

Launch Tidy Mac. Follow the friendly onboarding guide to grant Full Disk Access in macOS System Settings so it can scan caches and unneeded files.

4

Ad-Hoc Developer Notice

If macOS shows a security prompt on first open, simply right-click TidyMac.app → click Open, or run xattr -cr /Applications/TidyMac.app in Terminal.
